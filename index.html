Waarom Engels leren met games?

Je speelt al graag games? Prima! Je kan Engels leren terwijl je speelt. Door games in het Engels te spelen, hoor je echte Engelse woorden en kan je ze onthouden. Bovendien chat je met andere spelers uit de hele wereld. Hier lees je hoe je met Fortnite, Roblox en Minecraft je Engels kan verbeteren!

🎯 Fortnite

Wat is het spel?

Je bent in een eiland met nog 99 andere spelers. Je verzamelt wapens en vecht totdat je de enige bent die nog staat!

Hoe leer je Engels?
  • Taal op Engels zetten: Ga naar Settings → Language → English
  • Chat met je team: Praat met andere spelers via microfoon of tekstberichten
  • Leer wapennamen: Assault Rifle, Shotgun, Sniper
  • Kijk naar streamers: Zie hoe professionele spelers Engels spreken
  • Leer deze woorden: landing zone, loot, shield, eliminate, storm

🏗️ Roblox

Wat is het spel?

Een grote game-website met duizenden verschillende spelletjes. Je kan van alles spelen: race-games, bouw-games, rol-spel games. Alles met andere spelers samen!

Hoe leer je Engels?
  • Taal op Engels zetten: Klik op je profiel → Settings → Language → English
  • Chat in het spel: Veel games hebben een chat waar je met anderen kan typen
  • Lees de spelregels: Alle spelletjes hebben instructies in het Engels
  • Sluit je aan bij groepen: Veel spelers praten samen in groepen
  • Leer deze woorden: avatar, customize, game pass, level up, inventory
Ga naar Roblox →

⛏️ Minecraft

Wat is het spel?

Je bent in een wereld van blokken. Je kan bouwen wat je wilt, graven naar schatten, en tegen monsters vechten. Je kan het alleen spelen of samen met vrienden.

Hoe leer je Engels?
  • Taal op Engels zetten: Options → Language → English
  • Leer de bloknamen: Alle blokken hebben Engelse namen. Ontdek ze!
  • Speel op Engelse servers: Veel servers hebben spelers die Engels spreken
  • Kijk tutorials op YouTube: Leer bouwtechnieken van Engelse spelers
  • Leer deze woorden: crafting, mining, blocks, mobs, build, survival mode
